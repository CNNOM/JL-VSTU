# Программная инженерия (лабораторные работы)

## Описание
Этот репозиторий содержит несколько проектов, каждый из которых соответствует определенной задаче (Task) с номерами от 0 до 8. 
Каждый проект реализует конкретную функциональность и может быть запущен и протестирован отдельно.

# Структура репозитория
- LT-0: Делегирование
- LT-1: Абстрактный суперкласс
- LT-2: Фабричный метод
- LT-3: Хранитель
- LT-4: Итератор
- LT-5: Строитель
- LT-6: Прототип
- LT-7: Наблюдатель
- LT-8: Декоратор
